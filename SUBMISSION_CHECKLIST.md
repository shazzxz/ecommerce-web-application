# Submission Checklist

- [x] Product catalog with search and categories
- [x] Cart quantity controls and totals
- [x] Checkout with shipping details
- [x] Customer registration and login
- [x] Admin/customer role separation
- [x] Admin product create, update and delete
- [x] Customer order history
- [x] Admin order listing and status updates
- [x] Persistent database (SQLite locally; optional PostgreSQL through DATABASE_URL)
- [x] Responsive customer and admin screens
- [x] Payment gateway omitted; not required by the brief

## Demo flow

1. Start backend and frontend locally.
2. Register a customer account.
3. Browse the sample catalog, add products to cart, and check out.
4. Confirm the order appears in customer order history.
5. Log in using the admin credentials configured in .env.
6. Add/update a product and change an order status.
